# Tableau Connection Checklist

1. Download CSVs from GitHub or generate locally.
2. In Tableau Public: Connect → Text File → select CSV.
3. Confirm data types:
   - Dates as Date
   - Scores as Number (decimal)
   - Binary flags as Number (whole) or Boolean
4. Create calculated fields from CALCULATED_FIELDS.md
5. Build sheets per TABLEAU_DASHBOARD_BRIEF.md
6. Add filters for program enrollment and demographics
7. Publish to your Tableau Public profile
8. Update profile bio to reference the portfolio
